About Disk Scheduling

Understanding disk scheduling in Operating Systems

What is Disk Scheduling?

Disk scheduling is an operating system technique used to determine the order in which disk I/O requests should be processed. The main objective is to reduce head movement, improve disk performance and minimize access time.

Purpose of this Virtual Lab

This virtual laboratory provides an interactive environment for understanding SCAN and C-SCAN disk scheduling algorithms. Students can enter disk requests and observe the resulting seek sequence and total head movement.

Project Objectives

📚 Learn

Understand the working of disk scheduling algorithms.

📊 Visualize

Observe the movement of the disk head graphically.

⚡ Compare

Compare the performance of SCAN and C-SCAN.
