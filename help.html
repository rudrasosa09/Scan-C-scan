Learn how to use the Disk Scheduling Simulator

📌 How to use the simulator?

1

Enter the number of disk requests.

2

Enter the total number of tracks in the disk.

3

Enter the initial position of the disk head.

4

Select the direction of disk head movement.

5

Enter the track requests separated by commas.

6

Select SCAN or C-SCAN and click Run.

💡 Example Input

Number of Requests: 8

Total Tracks: 200

Initial Head: 53

Direction: Right

Requests: 98, 183, 37, 122, 14, 124, 65, 67

⚠️ Important

Make sure that the number of requests entered matches the number of track requests provided. Track numbers must be within the range of the disk.
